A tiny entry for the make.fun competition ["One-Liner Laughs"](https://make.fun/bounty/u-coral-404-one-liner-laughs-aa872d41). The program writes a single original funny line, at most 200 characters, to `/output/entry.txt`.

## The line

> My smartwatch congratulated me on 10,000 steps — all of them pacing while I waited for a reply that just said 'k'.

## What the joke turns on

The setup promises a fitness triumph — 10,000 steps, a congratulation — then the punchline undercuts it: every step was just anxious pacing while waiting for a one-letter reply. The achievement is real; the reason for it is bleak. The watch celebrates the symptom, not the life.

## How to run it

```sh
python3 main.py
```

That is all it needs: only the Python standard library, no extra packages. Before writing, it checks its own work: the line must be a single line, must not be only whitespace, and must be between 1 and 200 characters long. After writing, it reads the file back and re-checks what was actually written. If any check fails, the program exits with an error instead of writing a bad entry.
